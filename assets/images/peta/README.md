# PANDUAN PENGGANTIAN FOTO PETA KARSAKALA (ATLAS JAWA TENGAH)

Folder ini berisi 35 foto resmi untuk masing-masing Kabupaten dan Kota di Jawa Tengah pada halaman Peta Karsakala (**pages/peta.html**).

## 📸 Cara Mengganti Foto dengan Mudah

1. Siapkan foto baru yang ingin Anda gunakan.
2. Ubah nama file foto baru tersebut agar **sama persis** dengan nama file di tabel bawah (contoh: `peta-jepara.webp`, `peta-kota-semarang.webp`, dll).
3. Salin (*copy/paste*) foto baru tersebut ke dalam folder ini untuk menggantikan foto lama.
4. **Format file yang didukung:**
   - **.webp** (sangat direkomendasikan untuk kecepatan loading)
   - **.jpg / .jpeg** (sistem otomatis mendeteksi jika Anda menggunakan format JPG)
   - **.png** (sistem otomatis mendeteksi jika Anda menggunakan format PNG)
5. **Rekomendasi Dimensi Foto:**
   - Rasio: Landscape (16:9 atau 4:3)
   - Resolusi ideal: 800 × 480 piksel (atau minimal 600 × 360 piksel)
   - Ukuran file: Di bawah 200 KB agar website tetap ringan saat dibuka di HP
